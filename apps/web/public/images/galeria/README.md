# Gallery placeholder images

**These are temporary stand-ins, not LASCE photography.** The gallery at `/galeria` is built on
mock data (`apps/web/app/lib/gallery.ts`) while the laboratory's own photographs are collected.
Delete this directory and its README once real files are available; the data module is the only
other place that references these names.

Every file comes from the [NASA Image and Video Library](https://images.nasa.gov), restricted to
items produced by a NASA center, which are in the **public domain** and free to reuse. NASA does
not endorse this site, and no NASA logo or insignia is used.

Each original was downloaded from `images-assets.nasa.gov` and resized to 1200px on its longest
side (`sips -Z 1200 -s format jpeg -s formatOptions 80`). 36 files, 8.3MB total.

To look up an original: `https://images.nasa.gov/details/<NASA ID>`.
